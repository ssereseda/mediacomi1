# 🏠 Медиакоми

Интерактивный симулятор угадывания цен на квартиры в Республике Коми.

## 📖 Описание

«Медиакоми» — это веб-приложение, которое позволяет пользователям проверить свои знания рынка недвижимости Коми. В каждом раунде показывается 10 случайных объявлений о продаже квартир. Пользователь должен угадать цену каждой квартиры, используя бегунок.

## 🎮 Механика игры

1. **Старт** — на главной странице нажмите «Запустить игру»
2. **10 раундов** — в каждом раунде показывается объявление с фото и характеристиками
3. **Оценка** — передвиньте бегунок и нажмите «Оценить»
4. **Результат** — после 10 раундов показывается итоговый результат

### Система баллов

| Точность | Баллы |
|----------|-------|
| ≤ 3% | 10 |
| ≤ 7% | 8 |
| ≤ 15% | 6 |
| ≤ 25% | 4 |
| ≤ 40% | 2 |
| > 40% | 1 |

### Итоговые звания

- **🏆 Опытный инвестор** (70+ баллов) — близок к результату
- **💰 Щедрый инвестор** — переплачивает за недвижимость
- **🤏 Скряга** — экономный инвестор

## 📦 Деплой на GitHub Pages

### Автоматический деплой (рекомендуется)

Проект настроен на автоматический деплой через GitHub Actions.

1. Создайте репозиторий на GitHub:
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/mediacom-service-prototype-2e664.git
git push -u origin main
```

2. В настройках репозитория:
   - Перейдите в **Settings** → **Pages**
   - В разделе **Source** выберите **GitHub Actions**
   - Workflow запустится автоматически при каждом push в ветку `main`

3. После успешного деплоя сайт будет доступен по адресу:
   ```
   https://YOUR_USERNAME.github.io/mediacom-service-prototype-2e664/
   ```

### Ручной деплой

```bash
npm run build
# Загрузите содержимое папки dist/ в ветку gh-pages
```
